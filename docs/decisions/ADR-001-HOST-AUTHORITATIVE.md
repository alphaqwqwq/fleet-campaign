# ADR-001 房主权威与可替换实时适配器

- 状态：接受
- 日期：2026-08-13

## 背景

游戏需要临时房间联机。方案选择影响规则安全与后续扩展。

## 决定

- 房主（建房浏览器）是会话内唯一权威裁判：只接受经协议校验的命令意图，结算只发生在领域 reducer。
- 客机只能提交命令意图，不得提交伤害 / 骰子 / 资源 / 胜负等结果。
- 实时传输采用 PeerJS/WebRTC 的可替换适配器（`packages/realtime`），领域与协议不感知传输细节。
- 房主关闭后不迁移；提供保存 + 新建房间降级路径。

## 后果

- 领域规则可纯 TypeScript 独立测试，不受网络影响。
- 换传输方案只改 `packages/realtime`，不触碰领域 / 协议。
- 不承诺常驻服务、房主迁移、防作弊。

## 备选

- 常驻 WebSocket 服务端：更强的集中权威，但引入账号 / 部署 / 运营成本，超出首发范围。
