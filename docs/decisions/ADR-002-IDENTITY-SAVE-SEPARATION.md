# ADR-002 身份 / 资产标识分离与本地存档 v1

- 状态：接受
- 日期：2026-08-13

## 背景

房间、战役档、客户端、会话令牌四个概念容易混用，导致存档不可移植、认证越界。

## 决定

- `roomId`：临时房间定位，仅房主内存与消息中，不进存档。
- `campaignId`：长期战役资产，`c_` + UUIDv4，存于本地存档与快照。
- `clientId`：浏览器本地设备标识，`u_` + UUIDv4，用于命令归属与幂等范围，非账号。
- 会话令牌：房主为「房间 + clientId + 角色」签发，仅会话存储，绝不入 URL / 快照 / 存档 / 日志。
- 存档为 `schemaVersion: 1` 的 `CampaignSave`（含 `gameSnapshot`、`rngState`），导入失败不覆盖现有档案；未来用显式迁移链升级。

## 后果

- 四类标识各自独立生成方 / 作用域 / 失效条件，可测试。
- 首版无云同步、跨设备恢复、账号体系。

## 备选

- 账号 + 云存档：更强的连续性，但引入认证 / 服务端 / 数据合规成本，另立 Plan 再裁决。
