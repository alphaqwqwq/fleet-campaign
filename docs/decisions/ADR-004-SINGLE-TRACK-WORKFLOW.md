# ADR-004 采用单轨 git 驱动工作流

- 状态：接受
- 日期：2026-08-13

## 背景

旧流程把 Master / Plan / Exec / Review 角色映射为会话 × 工作树 × 分支的 4×4 组合，产生重复造轮子、撞车、重复评审与文档漂移。

## 决定

- git 是唯一真源；会话只执行，不承载状态。
- 一个工作树、一个长期驱动会话；每个工作单元一个 `feature/<slug>` 分支 + PR + CI + 合并即删。
- 评审只针对高风险改动（协议 / 存档 / 房主权威 / 跨包契约 / 发布架构），由只读子 agent 读 PR diff 完成。
- 只有跨契约变更写 ADR；不再写路线图 / 三行交接 / 会话命名等过程文档。

## 后果

- 流程成本与产品复杂度线性，不再被仪式放大。
- 恢复会话只需 `git log` + `decisions/`。

## 备选

- 保留角色会话，仅减少 worktree：仍保留标题 / 平台依赖 / 文档复刻的摩擦源，已否决。
