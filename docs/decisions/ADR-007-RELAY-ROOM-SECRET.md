# ADR-007 中继房间口令（防扫描脚本的轻量门卫）

- 状态：接受
- 日期：2026-08-19

## 背景

ADR-005 的 Vercel 轮询中继是无状态转发总线：房主签发会话令牌只在两端（房主/客机
浏览器）之间校验，中继不可见、不校验。因此**任何知道 `roomId` 的人都能**：

- `GET host-poll / guest-poll` 无鉴权读取任意房间的帧日志（对局事件流泄露）；
- `POST host-open` 对任意 5 位房间码无鉴权创建/接管房间；
- `POST host-send / guest-send` 无鉴权向房间注入帧。

本项目规模极小（小圈子 PVE、并发约 4 人、数百访问/月），真实恶意玩家针对性破坏
概率可忽略。实际威胁是**互联网上的自动化扫描脚本 / 无目的枚举器**（如 Shodan 类
批量探测）会：

1. 扫到 `/api/relay?op=host-open` 返回 `{ok:true}`，标记为"未授权写端点"；
2. 因 5 位房间码空间仅 10 万、且 poll 不存在房间返回 200 空数组，可**低成本枚举
   活跃房间**并读取他人对局。

## 决定

给中继增加一个**轻量房间口令（room secret）**，作为中继层的访问门卫。它**独立于**
房主签发的应用层会话令牌（ADR-002/001），语义是"谁能读/写这个房间的日志"。

- **生成**：房主 `host-open` 时生成 8 字符 base64url 口令（约 48-bit 熵），随
  `host-open` 请求体传入，中继把它存为房间元数据（作为一条特殊日志记录或独立键）。
- **分享码**：分享码 = `roomId + '-' + secret`（例 `37837-9f2kQx`）。房主展示完整
  分享码，客机输入后解析出 `roomId` 与 `secret`，后续 relay 请求携带 `secret`。
- **校验**：中继对该房间的**所有**操作（`host-poll` / `guest-poll` / `host-send` /
  `guest-send` / `host-close` / `host-close-client` / `guest-join` / `guest-leave`）
  均要求 `secret` 匹配，否则返回 `403 unauthorized`。`host-open` 首次创建时设置
  secret；再次 `host-open`（复用房间码）需携带当前房间 secret 才能接管，否则拒绝。
- **口令入 URL**：relay 是明文 HTTP 轮询，口令随 GET query 传递。这与 ADR-005
  "中继可见帧明文、无令牌"一致。对抗目标是扫描脚本/枚举器，不是网络窃听者。
- **断线重连**：口令与现有 `resumeToken` 一起持久化到 `sessionStorage`，reload 后
  自动恢复；房主/客机重连仍能继续 poll/send，**不退化**为"只能同步存档"。口令生命周期
  与房间一致（`host-close` / 1h TTL 后随房间日志失效）。
- **房间码**：维持 5 位数字（10000-99999，便于口述），口令承担防枚举职责。host-open
  的"房间占据检查"（`room_occupied`）保留。

## 后果

- 扫描脚本没有口令 → 无法 poll/send 任何房间（返回 403），无法枚举房间存在性
  （无口令一律 403，不再返回 200 空数组），`/api/relay` 在扫描器眼里不再是"软柿子"。
- 客机需输入完整分享码（含口令），口令入 URL query；对"复制粘贴分享码"的既有
  UX 无实质影响。
- 中继仍是**不透明转发总线**：只比对口令，不解析帧内容、不裁决（ADR-001/005 不变）。
- **不做的事**（明确边界）：
  - 口令是 48-bit，**不抗定向暴力破解**（那需 256-bit + 速率限制，超出 demo 范围）。
  - 不引入账号体系、不防网络窃听（TLS 之上的额外层超出范围）。
  - 中继口令 ≠ 应用层会话令牌，不取代房主侧的授权校验（ADR-001）。

## 备选

- **完全鉴权**（口令 + 签名 + 限流）：更强的安全保证，但引入密钥管理/签名/限流
  复杂度，与"小圈子 demo + 防扫描脚本"的目标不匹配，超范围。
- **只加边缘限流**（不改中继逻辑）：能挡扫描脚本频率，但无法阻止低频率枚举读取
  他人房间帧，且依赖平台能力。可作 ADR-007 的补充而非替代。
- **不处理**：维持现状，扫描脚本可无鉴权读/写任意房间。已实证（黑盒测试
  `host-open?room=00001` 返回 `{ok:true}`），否决。
