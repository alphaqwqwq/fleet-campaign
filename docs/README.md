# 文档索引

本目录只保存项目自身的流程、决策、架构与产品规格。原始规则书、模组 PDF、提取文本及其他外部参考资料必须保留在仓库之外的本地参考目录，不得提交到公开仓库。

## 内容

| 路径 | 内容 |
| --- | --- |
| `WORKFLOW.md` | 单轨开发流程：分支、门禁、评审、ADR 触发条件 |
| `ARCHITECTURE.md` | 包边界、依赖方向、组合层、测试策略 |
| `decisions/` | ADR 决策日志（跨契约变更的背景、决定、后果） |
| `reference/SPEC.md` | 现行产品契约：demo-v1 循环、协议 v1、存档 v1、实时降级 |

## 文档优先级

1. 已确认的规则约束与版本化 Schema（代码内）。
2. 已接受的 ADR（`decisions/`）。
3. 流程与架构规则（`WORKFLOW.md` / `ARCHITECTURE.md`）。
4. 产品规格（`reference/SPEC.md`）。

需要修改前两级的变更，先新增或更新 ADR，不得在代码中隐式改变约束。

## 历史

本仓库不维护进度/状态文档。当前分支、最近提交与发布记录以 `git log`、PR 与 Vercel 部署为准。
