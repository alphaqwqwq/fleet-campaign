# M2 UI 与星系背景基线

- 状态：视觉定稿（2026-08-13，经多轮 mockup 迭代与用户验收）
- 关联：[M2 设计基线](DESIGN-M2.md)；样稿在 `docs/reference/ui-mockups/`（holo-map.html 桌面 / orbit-editor.html 调参工具）
- 说明：不含具体舰船/人物美术，只定"棋盘与界面"的视觉语言、交互流、星系背景模型。

## 1. 视觉范式：暗控制台 + 青蓝全息

发光淡蓝全息地图（主体）+ 深色哑光控制台面板（数据/指令），经典科幻舰桥结构。核心是**对比度工程**：发光主体配暗色面板。

**色彩语义（跨地图与面板统一）**
```
我方=青蓝 #59d8ff   敌方=琥珀 #ffb34d   告警=红 #ff5a5a
充能=紫 #b78cff     背景=#05090d       面板=#0d1a24 / #0f2030
边框=#1b3a4d       文字=#c4dce8 / 弱#6f8fa1
```
设计令牌见样稿 `:root` CSS 变量；辉光 `0 0 8px rgba(89,216,255,.45)`。

## 2. 布局（桌面三栏；手机布局后置）

```
顶栏：品牌 + 回合 + 阶段指示（后勤/弹着/行动/接舷，右上）
┌左栏 我方数据──────┬中央 全息地图──────┬右栏 敌方+时间线──┐
│ 舰船卡(HP/防/计数) │ 带轨+舰船+星系背景 │ 敌舰卡+弹道/充能  │
│                   │ 底部指令坞(选中单位 │ 时间线           │
│                   │ 的机动/战术)       │                  │
└──────────────────┴──────────────────┴──────────────────┘
```
- 地图=选择/索敌主交互面；面板=数据/指令。选舰→指令坞→需目标进索敌→点敌方。
- 舰船 = 舰种符号（wowsdb 标准矢量，Path2D），地图上只留血量环，其余属性全在面板。
- 手机：全屏地图 + 可折叠底部 sheet（指令/舰队/时间线 tab），后置。

## 3. 星系背景模型（定稿）

- **轨道**：纯 2D 同心椭圆（Kepler，无伪 3D 压扁）。
- **摄像机** = 绕巨行星的卫星（a/T/phase 轨道 + follow 跟随目标 + yaw 偏航），俯视投影（ELEV/VIEWD，近低远高）。
- **光照**：Lambert 视角因子 `litFactor = dot(朝太阳, 朝相机)`——太阳在背后 → 阴面；阳面/阴面随摄像机轨道产生昼夜循环。
- **遮挡**：天体在巨行星盘内且比其近表更远 → 隐藏；太阳同样参与（被遮正确、无光晕、无避阳参数）。
- **默认背景配置**（编辑器导出，即样稿当前效果）：
```json
{ "bodies":[ {"a":360,"e":0.05,"T":300,"r":95,"phase":1.1,"name":"巨行星"},
             {"a":230,"e":0.12,"T":291,"r":47,"phase":3.4,"name":"岩质行星"},
             {"a":96,"e":0.03,"T":268,"r":12,"phase":2.2,"name":"卫星"} ],
  "camera": {"a":150,"T":120,"phase":0,"follow":"0","yaw":-0.09,"focal":410,"elev":42,"viewd":330} }
```
- **随机化方向**：星系类型（单星/双星/三体/巨行星+多卫星）+ 摄像机位置/朝向 → 每局/每任务换肤；配置即模板。
