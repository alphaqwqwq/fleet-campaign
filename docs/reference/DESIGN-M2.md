## 1. 电子化创造原则（本次固化）

**P1 引擎是内容消费者**：所有规则对象（船体 / 武器 / 系统 / 护航舰 / 机队 / 任务模板 / 环境）都是 schema 数据输入，引擎只认数据。量变→质变来自组合空间（构筑 × 任务 × 时序决策 × 持久伤痕），不来自 v1 写多少内容。以后加内容是加数据，不是重写逻辑。

**P2 决策可见性是一等公民**：时间维度、后果预览、检定透明与规则结算同等重要。自动化拿走的算术摩擦，用**决策摩擦**填补——每一轮选择 = 对未来的承诺（充能 / 鱼雷飞行 / 移动暴露），必须被看见。

**P3 填补体验缺失的五件事**：①决策承诺可见；②信息博弈与反事实预览；③时序/节奏成为主角（临界点、倒计时、充能节拍）；④检定透明作为仪式替代（可展开的 1d20+修正 vs 防御）；⑤构筑作为决策层的延伸。

**P4 叙事从状态涌现**：持久伤痕叙事（舰队伤疤 / 情报 / 标签跨场延续）由结算包 + 状态机驱动，不靠预写文本量。旁白 Hook 非权威、可降级（ADR-003）。

## 2. 已确认的设计决定

| 项 | 决定 |
| --- | --- |
| 多人模型 | 领域命令带 `actorId`（谁指挥哪个战斗群）、舰船带 owner（可 null）；**单指挥先行**（离线可玩，内存传输 + 本地存档），1-4 协控 + 观战为同一架构的扩展（后置） |
| 棋盘呈现 | 涡流盘 = **线性带轨**（6 环带：极限5/长4/瞄准镜3/坍缩2/近1/至近0）；桌面三栏，手机单列 + sticky；同心环仅作桌面装饰可选 |
| 行动者单位 | 战斗群（每玩家一战斗群），机动/战术以战斗群为单位 |
| v1 吸引锚 | 进：局外构筑（20 点 point-buy，数据层）+ 持久伤痕叙事（结算包/标签）；后置：晋升/军风/独特道具（状态模型现在铺） |

## 3. v1 范围筛选

**保留**：距离环带 + 移动；4 阶段轮次（后勤/弹着/行动/接舷，接舷先空转）；充能X/酬载X飞行/装填X 计数；攻击/伤害/阻滞/会心/准度难度骰；机动（全速前进/全舰开火/反向喷射）；战术（锁定/谨慎射击/紧急机动）；撤退/投降 + 临界点；交战结果判定（幸存比例）；SITREP 拦截/防御/护送；20 点构筑子集。

**后置**：服务期动作 / 储备 / 环境调整值 / 接舷战 / 军团空间 / 晋升 / 灰浴 / 通讯系统。
